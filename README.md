# دکترکی (DrKey)

دستیار بالینی **آفلاین** برای پزشک عمومی — فارسی، RTL، Progressive Web App.

## سازنده
**دکتر کیقباد** — [@mehdi_keyqobad](https://t.me/mehdi_keyqobad)

تشکر از **دکتر علی شاهسواری**

## نصب روی GitHub Pages

1. این مخزن را Fork کنید یا فایل‌ها را در یک repo جدید آپلود کنید.
2. از **Settings → Pages** منبع را `Deploy from a branch` روی `main` / `root` بگذارید.
3. چند دقیقه بعد آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.
4. روی موبایل با مرورگر باز کنید → **Add to Home Screen** برای نصب مانند اپ.

## فایل‌ها

| فایل | توضیح |
|------|--------|
| `index.html` | اپ کامل (تک‌فایلی + لینک آیکون و manifest) |
| `DrKey.html` | همان اپ (پشتیبان نام) |
| `manifest.json` | تنظیمات PWA |
| `icons/` | لوگوی برنامه در اندازه‌های مختلف |

## قابلیت‌ها (خلاصه)

- تخصص‌های بالینی با قالب ۵ ستونه (شرح‌حال، معاینه، پاراکلینیک، درمان، فالوآپ)
- تریاژ و ردفلگ بیماری‌محور
- کد و دوز دارو (از جمله اطفال)
- ماشین‌حساب و تفسیر آزمایش
- یادداشت متن + عکس با مرور درس‌محور
- بکاپ لوکال
- حالت تاریک و بزرگ‌نمایی

## اجرا محلی

فایل `index.html` را مستقیم در مرورگر باز کنید، یا:

```bash
npx serve .
```

> برای نصب PWA و Service Worker کامل، بهتر است روی HTTPS (مثل GitHub Pages) باشد.
