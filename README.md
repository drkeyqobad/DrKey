## فروش و فعال‌سازی

1. خریدار اپ را باز می‌کند → **کد شناسایی دستگاه** می‌بیند.
2. کد را در تلگرام برای شما می‌فرستد و پرداخت می‌کند.
3. شما `license-generator.html` را با مرورگر باز می‌کنید، کد را می‌گذارید، **کلید** می‌سازید.
4. کلید را به خریدار می‌دهید → وارد می‌کند → اپ باز می‌شود.
5. لایسنس روی همان گوشی در `localStorage` ذخیره می‌شود.

هر کلید فقط روی **همان دستگاه** کار می‌کند.

## نصب GitHub Pages

1. همه فایل‌های بالا (به‌جز license-generator) را در repo آپلود کنید.
2. Settings → Pages → Deploy from branch → `main` / root
3. آدرس: `https://USERNAME.github.io/REPO/`

### نصب به‌صورت اپ (PWA)
بعد از آپلود **حتماً پوشه icons** هم باشد. سپس در کروم: Install app.

## محدودیت امنیتی (صادقانه)

چون اپ کاملاً سمت‌مرورگر است، کاربر فنی می‌تواند لایسنس را دور بزند. این سیستم جلوی **اشتراک‌گذاری عادی** و کپی بین گوشی‌ها را می‌گیرد و برای فروش به همکاران مناسب است. برای امنیت خیلی بالا بعداً می‌توان سرور فعال‌سازی اضافه کرد.
